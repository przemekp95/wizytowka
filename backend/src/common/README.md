# Common Utilities

Shared utilities, guards, middleware, and common functionality used across the application.

## Description

This directory contains common code shared across multiple modules including authentication guards, custom middleware, decorators, pipes, and utility functions.

## Getting Started

### Dependencies

* NestJS framework
* TypeScript 5.9+
* Common utilities and helpers

### Installing

* Common modules are automatically imported where needed
* No additional installation required
* Available globally across the application

### Executing program

* Common utilities are loaded automatically with the application
* Guards and middleware are applied to routes as configured
```
npm run start:dev
```

## Help

For common utilities issues, check imports and ensure modules are properly configured in the main application module.
