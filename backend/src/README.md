# Backend Source Code

Main backend application source code directory containing all server-side logic and functionality.

## Description

This directory contains the core backend application code including controllers, services, modules, entities, and all business logic for the portfolio/contact management system.

## Getting Started

### Dependencies

* Node.js 18+
* NestJS framework
* TypeScript 5.9+
* Prisma ORM
* AWS SDK
* Various NestJS packages

### Installing

* Install dependencies: `npm install` or `pnpm install`
* Configure environment variables in `.env` file
* Run database migrations: `npx prisma migrate dev`

### Executing program

* Start development server: `npm run start:dev` or `pnpm run start:dev`
* Run tests: `npm run test` or `pnpm run test`
* Build for production: `npm run build` or `pnpm run build`
```
npm run start:dev
```
