# Portfolio Module

Portfolio management functionality for showcasing projects and work samples.

## Description

This module handles portfolio-related operations including project management, portfolio display, and API endpoints for retrieving and managing portfolio content.

## Getting Started

### Dependencies

* NestJS framework
* TypeScript 5.9+
* Prisma ORM for database operations
* Portfolio entities and DTOs

### Installing

* Module is automatically imported in the main application module
* Database schema includes portfolio-related tables
* No additional installation required

### Executing program

* Portfolio endpoints are available when the application runs
* Use REST API or GraphQL to interact with portfolio functionality
```
npm run start:dev
```

## Help

For portfolio module issues, check database connectivity and ensure portfolio tables exist in the schema.
