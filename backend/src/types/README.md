# Type Definitions

TypeScript type definitions and interfaces used across the application.

## Description

This directory contains custom TypeScript type definitions, interfaces, enums, and type utilities that are shared across different modules of the application.

## Getting Started

### Dependencies

* TypeScript 5.9+
* Type definitions for external libraries
* Custom interface definitions

### Installing

* Type definitions are automatically included in TypeScript compilation
* No additional installation required
* Available globally across the application

### Executing program

* Types are used during TypeScript compilation and type checking
* No runtime execution required
```
npx tsc --noEmit
```

## Help

For type definition issues, check TypeScript compilation errors and ensure all imports are correct.
