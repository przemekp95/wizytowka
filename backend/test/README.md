# Tests

Test files and test configuration for the backend application.

## Description

This directory contains all test files including unit tests, integration tests, end-to-end tests, and test configuration files for the backend application.

## Getting Started

### Dependencies

* Jest testing framework
* @nestjs/testing
* Supertest for HTTP testing
* TypeScript 5.9+
* Test utilities and helpers

### Installing

* Test dependencies are included in package.json
* Install with: `npm install` or `pnpm install`
* No additional installation required

### Executing program

* Run all tests: `npm run test` or `pnpm run test`
* Run tests in watch mode: `npm run test:watch`
* Run e2e tests: `npm run test:e2e`
```
npm run test
npm run test:e2e
```

## Help

For testing issues, check test configuration, ensure all dependencies are installed, and verify test environment setup.
