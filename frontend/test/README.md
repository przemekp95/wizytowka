# Frontend Tests

Test files and test configuration for the frontend application.

## Description

This directory contains the frontend test suite, including Vitest unit/component tests and Playwright browser tests.

## Getting Started

### Dependencies

- Vitest testing framework
- React Testing Library
- Playwright for e2e tests
- TypeScript 5.9+
- Test utilities and helpers

### Installing

- Test dependencies are included in package.json
- Install with `pnpm install`
- No additional installation required

### Executing program

- Run unit and component tests: `pnpm run test`
- Run tests in watch mode: `pnpm run test:watch`
- Run e2e tests: `pnpm run test:e2e`

## Help

For testing issues, check the Vitest and Playwright configuration, ensure all dependencies are installed, and verify test environment setup.
