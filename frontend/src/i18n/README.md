# Internationalization

Internationalization (i18n) configuration and translation files for the frontend application.

## Description

This directory contains internationalization setup including configuration, translation files, routing, and utilities for supporting multiple languages in the application.

## Getting Started

### Dependencies

- Next.js 15+
- React 18+
- TypeScript 5.9+
- i18n libraries and utilities
- Translation management

### Installing

- Internationalization is configured in the main application
- Translation files are in the messages directory
- No additional installation required

### Executing program

- i18n is initialized when the application starts
- Translations are loaded based on user locale

```
npm run dev
```

## Help

For internationalization issues, check configuration files, ensure translation files exist, and verify locale detection setup.
