# App Directory

Next.js App Router directory containing pages, layouts, and route handlers.

## Description

This directory contains the Next.js application structure using the App Router including pages, layouts, loading components, error boundaries, and API routes.

## Getting Started

### Dependencies

- Next.js 15+
- React 18+
- TypeScript 5.9+
- App Router features

### Installing

- App directory is part of the Next.js application structure
- No additional installation required
- Components and pages are automatically routed

### Executing program

- Pages are automatically served by Next.js development server
- Navigate to routes using Next.js routing system

```
npm run dev
```

## Help

For App Router issues, check Next.js documentation, ensure proper file naming conventions, and verify component exports.
