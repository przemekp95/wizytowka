# Components

Reusable React components used throughout the frontend application.

## Description

This directory contains all reusable React components including UI components, form components, layout components, and other shared components used across different pages.

## Getting Started

### Dependencies

- React 18+
- TypeScript 5.9+
- Component libraries and utilities
- Styling frameworks (Tailwind CSS, etc.)

### Installing

- Components are part of the main application
- No additional installation required
- Import and use components in pages and other components

### Executing program

- Components are rendered as part of the React application
- No separate execution required

```
npm run dev
```

## Help

For component issues, check component props, ensure proper imports, and verify component exports and TypeScript types.
