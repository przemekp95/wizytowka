# Frontend Source Code

Main frontend application source code directory containing all client-side logic and components.

## Description

This directory contains the core frontend application code including Next.js pages, components, utilities, internationalization, and all client-side business logic.

## Getting Started

### Dependencies

- Next.js 15+
- React 18+
- TypeScript 5.9+
- Tailwind CSS
- Various React libraries

### Installing

- Install dependencies: `npm install` or `pnpm install`
- Configure environment variables in `.env.local` file
- No additional setup required

### Executing program

- Start development server: `npm run dev` or `pnpm run dev`
- Build for production: `npm run build` or `pnpm run build`
- Start production server: `npm run start` or `pnpm run start`

```
npm run dev
```
